## Dataset

RetailPulse uses the **Brazilian E-Commerce Public Dataset by Olist**, available on Kaggle.

- **Source:** [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- **Platform:** Kaggle
- **Contents:** Approximately 100,000 orders from 2016 to 2018, covering customers, orders, products, sellers, payments, reviews, and geolocation.

### Setup

1. Download the dataset from Kaggle.
2. Extract the CSV files.
3. Place all nine CSV files inside the `data/` directory in the project root.
4. Follow the project setup instructions to initialize the database.
